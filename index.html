Tokens

            
CSS variables for color, spacing, shape, and motion. Use the named roles like --surface and --text instead of raw color values, so light and dark mode both work.

          

        


        

          
--bgPage background

          
--surfacePanel background

          
--surface-subtleGrouped rows

          
--textBody text

          
--accentVivid accent, for fills without text

          
--accent-surfaceAccent behind white text

          
--accent-inkInk for a glyph on --accent

          
--focus-colorFocus ring

        


        

          

            
Three fonts, three jobs.

            
IBM Plex Sans is for interface text. Plex Serif is for long-form reading. Plex Mono is for code, IDs, and numbers. Setting data-type changes which one headings use.

          

          

            
Spacing
--space-1 through --space-8

            
Corners
--radius-sharp --radius-compact --radius-soft

            
Motion
--duration-*, all with an ease-out curve

            
Focus
A solid outline plus a soft halo behind it

AI design tells

            
Patterns that make a page look machine-generated. Each row says what it looks like and what to do instead.

          

        


        

          

            
TellWhat it looks likeWhat to do instead

            
              
Template structureCentered hero, three equal features, oversized closing CTALead with the actual task, data, or object

              
Decorative containersEvery idea is a rounded card; cards sit inside cardsUse headings, spacing, and rules; frame only the main work area

              
Premium styling by defaultGlass, glow, large radii, and soft shadows everywhereUse flat or outlined surfaces; reserve depth for actual layering

              
Stacked technical signalsDark mode, sharp corners, grid-paper texture, and heavy mono type all at onceKeep corners moderate and texture off unless the surface is genuinely technical; use one strong technical signal at most

              
Synthetic colorPurple-blue gradients, cyan on dark, radial halosUse one grounded accent and semantic state colors

              
Filler structureEyebrow labels above headings and arbitrary section numbersLet the headings and the order of the content do that job

              
Icon tilesA rounded square icon above every headingUse icons only when they clarify an action or object

              
Decorative codeTerminal dots, blinking cursors, or code texture without codeShow a real command, log, diff, or payload

              
Decorative fillerAbstract blobs, fake charts, ornamental dashboardsShow something real from the product, or an empty state

              
Vague copy"Transform your workflow" and other interchangeable claimsSay what it does and what happens as a result

              
Invented evidenceMade-up metrics, quotes, logos, people, and customersUse real data, label sample data as sample, or leave it out

              
Repetitive motionEvery element lifts, glows, pulses, or reveals the same wayKeep state changes quiet, and pick one place for real motion
