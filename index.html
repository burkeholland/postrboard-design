Disclosure

            

              

                
What needs application JavaScript?
Focus trapping, Escape handling, roving focus, selection state, and announcements are behavior. CSS supplies the visual shell only.

                
Can axes be scoped?
Yes. Scope visual axes when product meaning changes. Keep mode on the page root; for an opposite-mode island, set its mode, accent, and surface together.

AI design tells

            
One property is rarely the problem. Repeated, context-free choices create the tell.

          

        


        

          

            
TellSymptomReplacement

            
              
Template structureCentered hero, three equal features, oversized closing CTALead with the real workflow, evidence, data, or object

              
Container reflexEvery idea is a rounded card; cards sit inside cardsUse hierarchy, spacing, rules, and one framed work surface

              
Default premiumGlass, glow, large radii, and soft shadows everywhereUse flat or outlined surfaces; reserve depth for actual layering

              
Cold technical stackingDark mode, sharp corners, grid-paper texture, and heavy mono type combined by defaultKeep corners moderate and texture off unless the surface is genuinely technical; use one strong technical signal at most

              
Synthetic colorPurple-blue gradients, cyan on dark, radial halosUse one grounded accent and semantic state colors

              
Generator scaffoldingEyebrows above headings and arbitrary section numbersLet headings and content order carry structure

              
Icon tilesA rounded square icon above every headingUse icons only when they clarify an action or object

              
Fake technicalityTerminal dots, blinking cursors, or code texture without codeShow a real command, log, diff, or payload

              
Empty spectacleAbstract blobs, fake charts, decorative dashboardsShow a product artifact or an honest empty placeholder

              
Vague copy"Transform your workflow" and other interchangeable claimsName the input, action, output, and consequence

              
Fake proofInvented metrics, quotes, logos, people, and customersUse supplied evidence, label sample data, or remove it

              
Mechanical motionEvery element lifts, glows, pulses, or reveals the same wayUse quiet state changes and one purposeful motion moment

              
Missing behaviorA polished default with no focus, error, loading, or empty stateBuild the state model before decoration

Behavior is not CSS
Modal, drawer, dropdown, combobox, tabs, and popover classes provide presentation. Application code must provide keyboard behavior, focus management, state, and announcements.
