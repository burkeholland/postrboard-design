what ships

A design system hiding in one stylesheet.

01

Token-first

Every value flows from one design token contract, so surfaces, spacing, type, and focus states stay coherent.

02

Zero JavaScript

Pure CSS components that just work: buttons, cards, terminals, forms, badges, grids, and layout primitives.

03

Dark mode built in

System preference detection plus manual toggles via data-mode. Atmospheric dark, not inverted light.

quick start

Install by doing almost nothing.

Paste a link tag, then compose real interfaces with readable classes like container, stack, card, and btn-primary.

<!-- Link directly --> <link rel="stylesheet" href="https://burkeholland.github.io/postrboard-design/postrboard.min.css"> <!-- or npm --> $ npm install postrboard-css
